## 五、多字 / 漏字常见错误

### 多字错误

| 错误写法 | 正确写法 | 说明 |
| --- | --- | --- |
| 的的 | 的 | 「的」重复 |
| 了了 | 了 | 「了」重复 |
| 是是 | 是 | 「是」重复 |
| 这这 | 这 | 「这」重复 |

| 非非常 | 非常 | 「非」重复 |
