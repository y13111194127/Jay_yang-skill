# 场景结构规则

## 使用原则
本文件只决定“怎么组织”，不补充事实。先识别场景功能，再选择结构。不得把所有讲话强制写成“成绩—问题—措施”或固定三点式。结构节点没有可靠素材时，删除非必要节点；确属文种必需但事实缺失时使用 `〔待补充〕` 或 `〔待核实〕`。

## 场景判定顺序
1. 先判断是否为主持、致辞等强场景文种；强场景优先服从对应文种规则。
2. 再判断会议功能：部署、动员、总结、专题分析、调研座谈、学习辅导、开幕闭幕、交流、述职述责等。
3. 同一任务出现多个功能时，确定一个主功能，其余只作为局部段落，不拼接多个完整模板。
4. 结构必须服务讲话目的、身份和受众；不能因素材中存在成绩就强行设置“成绩回顾”章节。

## 工作部署场景
适用：部署会、推进会、任务交办会、专项工作会。

推荐结构：
`开场定题 → 当前基础/约束 → 目标与边界 → 重点任务 → 责任分工 → 节点与标准 → 保障/督办 → 收束`

控制规则：
- 重点任务必须能回答“谁做、做什么、做到什么程度、何时完成”；材料未提供责任主体或期限时不得编造。
- 若输入仅有任务，没有成绩或问题材料，可直接从任务背景进入部署。
- 责任要求必须与讲话人权限相符。

## 动员启动场景
适用：专项行动启动、攻坚阶段启动、集中整治启动。

推荐结构：
`为什么现在做 → 本次行动解决什么 → 做到什么 → 怎么组织实施 → 谁负责 → 如何检查反馈 → 动员收束`

控制规则：
- “紧迫性”只能来自已知风险、节点、任务要求或现实问题，不得制造危机。
- 动员语言可增强节奏，但必须落到行动，不连续使用口号式排比。

## 推进调度场景
适用：项目推进会、阶段调度会、督办会。

推荐结构：
`进展判断 → 卡点/差距 → 分项处置 → 协同关系 → 时间节点 → 督办反馈`

控制规则：
- 进展评价必须有材料支撑。
- 对问题可归纳但不得擅自认定责任单位或原因。
- 已明确节点优先保留原时间表述，不得自行提前或延后。

## 总结复盘场景
适用：年度总结、阶段总结、活动总结、专项工作收官。

推荐结构：
`回顾范围 → 主要做法 → 有依据的成效 → 问题不足 → 可成立的经验 → 后续安排 → 收束`

控制规则：
- 成效、经验、问题分别标记来源，不能把推断变成结论。
- 没有充分证据时，宁可写“取得阶段性进展”也不得自行写“成效显著”。
- “经验”必须能从做法和结果中提炼，不能预设万能经验。

## 专题分析场景
适用：围绕单一政策、业务问题、改革事项、风险事项作讲话。

推荐结构：
`界定问题 → 现状事实 → 关键矛盾/问题 → 原因或约束 → 对策 → 落实要求`

控制规则：
- 原因分析没有材料支撑时，只写可直接由事实推出的弱判断，不写确定性归因。
- 专业概念首次出现时可做必要解释，但不得自行创造政策定义。

## 调研座谈场景
适用：调研座谈会、听取汇报后的讲话、基层走访交流。

推荐结构：
`回应现场/来意 → 对已掌握情况作判断 → 点出值得关注的问题 → 提出针对性意见 → 明确后续衔接`

控制规则：
- 不虚构“刚才大家谈得很好”“我一路看了”等现场经历。
- 若确有发言材料，可概括共同问题，但不得给未提供观点的人“代言”。
- 语气应比部署讲话更具交流感，但仍正式克制。

## 学习辅导/宣讲场景
适用：政策学习、专题辅导、理论宣讲、培训开班辅导。

推荐结构：
`学习背景 → 核心内容/主旨 → 与本地区本单位工作的关系 → 落实重点 → 学习要求`

控制规则：
- 政策原意、文件名称、条款必须有可靠素材。
- 不得凭记忆引用领导原话、政策原文或具体条款。
- 面向非专业受众时优先解释概念和行动影响。

## 开幕/开班场景
推荐结构：
`称谓 → 欢迎/问候 → 活动事实 → 举办意义 → 对参与者的期望 → 宣布/祝愿`

控制规则：
- 课程、嘉宾、人数、举办届次等均须有依据。
- 开幕致辞不扩展成工作部署，除非任务明确要求。

## 闭幕/结业场景
推荐结构：
`回顾活动 → 有依据的收获/成果 → 感谢 → 后续期望 → 宣布结束/祝愿`

控制规则：
- 未提供成果时不能虚构“达成广泛共识”“取得圆满成功”。
- “圆满结束”等结论需与材料和场景相符。

## 交流研讨场景
推荐结构：
`问题背景 → 本单位做法 → 证据/结果 → 反思与局限 → 可供借鉴点 → 交流收束`

控制规则：
- 交流不是宣传，必须允许保留局限和条件。
- 不把个案做法夸大为普遍规律。

## 述职述责类场景
适用：用户明确要求述职、述责、履职发言，但仍以讲话/发言稿形态交付。

推荐结构：
`职责范围 → 履职事项 → 结果与不足 → 问题原因（有依据时） → 改进安排`

控制规则：
- 只写已提供或已检索核验的职责与结果。
- 不替讲话人增加无依据的政治表态、个人成绩或自我评价。

## 结构自然度
- 一级逻辑一般 2—6 个核心板块；数量由事实和任务决定，不强制三段。
- 同级小标题应属于同一抽象层次，但不要求字数完全对称。
- 段落之间优先使用语义承接，不为“顺滑”机械加入“首先、其次、再次、最后”。
- 开头应尽快进入现场任务；结尾应回到行动、责任、期望或礼仪功能，不重复全文摘要。
