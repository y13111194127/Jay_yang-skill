# 文种规则

## 使用原则
本文件供 Qwen3.5:27b 按确定性规则生成正式政务文本，不作为聊天话术。先按任务目的、使用场景、讲话人身份、受众和格式选择文种，再规划结构。不得因为“讲话”二字就不强行套用一个模板或三点结构；示例不是固定 copy，事实和任务数量决定段落数量。

现场讲话与非现场文本必须区分：现场输出保留称谓、开场、可听的过渡、主体、收束，必要时标注主持动作或停顿；非现场输出按输入和文种保留标题、称谓、正文、结尾、署名和日期，不能擅加现场口语。标题、称谓、正文、结尾、落款均按输入要求和文种取舍。缺失信息使用批准占位符，不补造事实。不得添加助手前言、后记、说明、建议或聊天框架。

## 快速选择矩阵

| 常见意图 | 优先文种 | 判断重点 | 输出倾向 |
| --- | --- | --- | --- |
| 现场作总体部署、讲形势和责任 | 讲话稿 | 是否需要完整判断与部署 | 现场完整讲话 |
| 面向听众表达个人观点并形成现场感染力 | 演讲稿 | 是否有观点张力和演讲节奏 | 现场完整演讲 |
| 代表岗位在会议上汇报认识和措施 | 发言稿 | 是否突出发言人职责 | 现场发言，不替代报告 |
| 对任务作出明确承诺 | 表态发言 | 是否需要逐项承诺 | 短而有力的现场发言 |
| 负责会议流程和串联 | 主持词 | 是否包含议程、转场和提示 | 仅主持人台词 |
| 活动开场、欢迎、闭幕祝愿 | 致辞 | 是否以礼仪沟通为主 | 现场或书面致辞 |
| 提高紧迫感并组织行动 | 动员讲话 | 是否要把动员落到任务责任 | 现场动员 |
| 回顾阶段工作并安排后续 | 总结讲话 | 是否需要问题、经验和下一步 | 现场总结 |
| 围绕会议主题作综合讲话 | 会议讲话 | 会议目的决定结构 | 按会议功能取舍 |
| 聚焦一个问题作分析指导 | 专题讲话 | 是否有证据和针对性措施 | 专题现场讲话 |
| 明确目标、任务、分工和节点 | 工作部署讲话 | 责任主体和时限是否清楚 | 可执行的现场部署 |
| 分享本单位实践供交流 | 交流发言 | 是否说明做法、证据和边界 | 经验交流发言 |
| 提炼可复制的典型做法 | 典型经验发言 | 机制、证据和复制条件 | 克制的经验发言 |
| 面向公众传播事实和做法 | 宣传稿 | 是否以事实导语切入 | 非现场传播文本 |
| 面向公众说明情况并提出行动期待 | 公开信 | 对象是否明确、语言是否易懂 | 非现场公开文本 |
| 对具体帮助表达谢意 | 感谢信 | 帮助和影响是否具体可核 | 非现场书信 |

## 讲话稿
### 用途
用于正式会议或活动中，由领导或负责同志就形势、任务和责任作完整讲话，兼顾判断、部署与现场传达。
### 必要结构
场景开头与称谓 → 说明会议或工作背景 → 形势判断和问题 → 工作安排 → 责任要求 → 现场收束。按任务需要增删，不固定三段。
### 语气
正式、稳健、有现场感；判断要有材料支撑，部署要有对象和动作，避免只讲态度。
### 完整稿要素
现场称谓、开场目的、情势判断、工作部署、责任要求、节点或反馈方式、结束语；非现场稿按要求保留标题、正文、落款日期。
### 禁止项
不得写成完整工作报告或宣传稿；不得只有情势判断、工作部署、责任要求的空框架；不得虚构政策、数据、会议和成绩。

## 演讲稿
### 用途
用于面向听众阐述明确观点、回应现实问题并形成现场表达效果，重视听感但仍属正式政务文本。
### 必要结构
称谓或开场 → 具体场景或问题 → 核心观点 → 事实与论证 → 观点推进和行动指向 → 收束。观点应有事实落点。
### 语气
比一般讲话更重节奏、现场感、情绪和观点张力，但正式、克制、讲事实；可用短句和适度反问，不追求戏剧化。
### 完整稿要素
标题（如要求）、称谓、可听开场、中心观点、事实例证、段落节奏、面向受众的行动或思考、结束语。
### 禁止项
不得写成议论文或鸡汤；不得用网络语言、虚构故事、金句堆叠或无依据煽情；不得因追求感染力而拔高事实。

## 发言稿
### 用途
用于特定讲话人围绕会议主题表达岗位职责、会议主题、认识、措施、态度、落实，通常是会议中的一位发言。
### 必要结构
称谓 → 结合岗位说明认识 → 讲本职工作或承担事项 → 提出措施 → 表明落实态度 → 简洁结束。
### 语气
正式、具体、谦实；体现发言人角色，不抢代主要讲话人的总体部署。
### 完整稿要素
讲话人身份、会议主题、岗位职责、认识、措施、态度、落实动作和结束语；现场发言保留称谓，书面交流按要求加标题。
### 禁止项
不得写成全单位工作报告，不得泛讲全局而没有岗位动作，不得虚构发言人权限、成绩或承诺。

## 表态发言
### 用途
用于接受任务、回应要求或面对问题时明确立场、承接责任并作出可检查的落实承诺。
### 必要结构
对任务或问题的认识 → 明确态度 → 承担责任 → 具体措施 → 时限、标准或反馈承诺 → 收束。
### 语气
简洁、坚定、有力度；每项态度后接实际动作，承诺强度与权限和材料相符。
### 完整稿要素
现场称谓、表态对象、立场、责任、具体措施、承诺、反馈或检查节点、结束语。
### 禁止项
不得只写空泛态度，不得用口号代替动作，不得承诺无权决定的事项，不得虚构整改结果。

## 主持词
### 用途
用于主持会议、活动或仪式，控制流程、提示环节并完成会场转场，不承担发言人的内容职责；核心是议程、转场、称谓、现场提示。
### 必要结构
开场问候 → 宣布会议或活动名称 → 介绍已核实的议程与人员 → 环节转场 → 提示发言、休会或合影 → 总结流程并宣布结束。
### 语气
清楚、简短、礼貌、可执行；语言适合当场听取，时间和动作提示明确。
### 完整稿要素
主持人称谓、会议名称、议程顺序、已确认的嘉宾和职务、转场话术、现场提示、结束宣布；未提供的信息用占位符。
### 禁止项
不得替发言人撰写观点，不得虚构嘉宾、议程或结果，不得擅自增加环节、口号、背景评价或现场指令。

## 致辞
### 用途
用于会议、活动、庆典或交流场合的欢迎、开幕、闭幕、祝贺和送别，核心是礼仪沟通与主题表达。
### 必要结构
称谓 → 问候、欢迎或感谢 → 交代活动事实和主题 → 表达必要认识 → 提出期望或祝愿 → 结束礼语。
### 语气
庄重、亲切有分寸；礼貌表达服务于事实主题，不用泛泛赞美替代内容。
### 完整稿要素
标题（按要求）、现场称谓、问候、欢迎或感谢、事实主题、期望祝愿、对参与者的尊重、落款日期（书面要求时）；核心要素是问候、欢迎或感谢、事实主题、期望祝愿。
### 禁止项
不得虚构嘉宾姓名、身份、活动成果、合作成果或礼仪事实；不得把致辞写成工作部署或专题报告。

## 动员讲话
### 用途
用于任务启动、专项行动或关键阶段，统一认识、说明紧迫性并把人员组织到具体行动中；核心要素是紧迫性、边界、目标、任务、责任。
### 必要结构
形势与紧迫性 → 任务边界 → 工作目标 → 重点任务 → 责任分工 → 动员要求与保障 → 收束。
### 语气
有号召力但不喧喊；紧迫性必须对应风险、节点或任务，要求必须能执行。
### 完整稿要素
现场称谓、动员对象、紧迫原因、目标、任务清单、责任主体、时限、督导反馈和结束动员。
### 禁止项
不得只有口号没有行动，不得制造危机感，不得把愿望写成已完成结果，不得虚构上级部署或任务边界。

## 总结讲话
### 用途
用于阶段性会议、活动或专项工作结束时回顾过程、评价成效、指出不足并安排后续；核心要素是工作回顾、证据化成效、问题、经验、下一步。
### 必要结构
会议或工作回顾 → 有证据的结果 → 可解释的经验 → 问题和不足 → 下一步安排 → 结束要求。
### 语气
实事求是、平衡克制；评价与证据相称，既不回避问题，也不把经验绝对化。
### 完整稿要素
称谓、回顾范围、工作做法、证据化成效、问题、经验、下一步任务、责任或时间节点、收束。
### 禁止项
不得只报喜，不得报告只有好消息，不得发明成绩、数据、先进典型或原因；不得把总结写成新一轮动员口号。

## 会议讲话
### 用途
用于正式会议中的综合性讲话，具体结构由会议目的决定，可承担传达、分析、部署、总结或统一认识中的一种或多种功能。
### 必要结构
开场与会议背景 → 核心判断 → 围绕会议目的讲问题或任务 → 落实要求 → 结束。会议目的不同时，结构随之调整。
### 语气
正式、清晰、面向会议现场；既有全局判断也要回到参会单位的职责。
### 完整稿要素
会议名称和对象、召开缘由、主题判断、与议题对应的事实、任务或要求、责任节点、现场收束。
### 禁止项
不得套用“万能会议讲话”或泛泛通用 prose，不得把所有会议都写成部署会，不得虚构会议议题、决议或参会范围。

## 专题讲话
### 用途
围绕一个明确政策、问题、领域或专项主题作分析、指导和部署，服务于理解问题和解决问题。
### 必要结构
界定专题与边界 → 事实和当前情况 → 问题分析 → 针对性措施 → 工作要求与收束。
### 语气
专业、审慎、聚焦；概念必须解释并落到对象、环节和动作。
### 完整稿要素
主题、对象、范围、证据、现状判断、问题原因、对应措施、责任要求、必要的节点和结束语。
### 禁止项
避免概念堆叠、空泛理论和跨主题发散；不得把未经核验的判断写成结论，不得以专题名义罗列万能措施。

## 工作部署讲话
### 用途
用于把确定目标转化为任务安排，明确谁在何时按什么要求完成什么工作；核心要素是目标、任务、分工、节点、保障。
### 必要结构
工作目标 → 重点任务 → 责任分工 → 时间节点 → 标准和反馈 → 保障与纪律 → 收束。
### 语气
直接、明确、可执行；行动主体、动作、完成条件和期限应尽量同句呈现。
### 完整稿要素
称谓、目标、任务清单、牵头与配合主体、节点、验收或报送标准、保障措施、责任追究或提醒、结束语。
### 禁止项
不得只写方向而无责任主体，不得使用“有关部门”掩盖分工，不得虚构期限、考核结果或保障资源。

## 交流发言
### 用途
用于介绍本单位或本人在特定工作中的实践，供参会者比较、借鉴和讨论；核心要素是背景、做法、证据、结果、局限、可迁移启示。
### 必要结构
交流背景 → 遇到的问题 → 采取的做法 → 事实证据与结果 → 局限 → 可迁移启示或请教事项。
### 语气
平实、开放、互鉴；讲清过程和条件，不作无依据的自我表扬。
### 完整稿要素
发言人和单位角色、场景、实践对象、措施、机制、证据、实际结果、局限、适用条件和交流收束。
### 禁止项
不得自夸，不得把个别做法写成普遍规律，不得虚构案例、数据、反馈或“可复制”结论。

## 典型经验发言
### 用途
用于提炼具有代表性的实践经验，说明其如何解决问题、形成机制，并供其他地区或单位参考；核心要素是背景、问题、行动、机制、证据、局限、复制条件。
### 必要结构
背景 → 原有问题 → 关键行动 → 运转机制 → 证据和结果 → 局限 → 复制条件与启示。
### 语气
具体、克制、可验证；先讲事实，再提炼经验，明确经验成立的范围。
### 完整稿要素
问题场景、对象、行动步骤、责任机制、资源条件、证据、实际结果、局限、复制条件、交流请求或结束语。
### 禁止项
不得编造成绩或把个案普遍化，不得删去成本、条件和局限，不得用“放之四海而皆准”替代复制分析。

## 宣传稿
### 用途
用于面向公众传播政策落实、公共活动、基层实践或典型事实，帮助读者快速了解发生了什么；核心要素是事实导语、行动、实际结果、克制收束。
### 必要结构
事实导语 → 具体行动和场景 → 实际结果 → 必要背景或人物细节 → 克制收束。篇幅和媒体格式按输入调整。
### 语气
准确、清晰、适度生动；以事实带动阅读，不用过度宣传腔。
### 完整稿要素
标题、事实导语、时间地点（有依据时）、行动主体、过程细节、实际结果、公众相关性、克制结尾；非现场一般无现场称谓。
### 禁止项
不得使用现场称谓或代替讲话人发言，不得无依据表扬、夸大影响或编造数据、人物、成果。

## 公开信
### 用途
用于机关、组织或责任主体面向明确公众群体公开说明情况、沟通立场、提出行动安排或表达共同期待。
### 必要结构
标题 → 面向对象的称谓 → 情况说明 → 核心事项 → 行动安排或期望 → 收束 → 署名、日期（按要求）。
### 语气
清楚、公开、友好、负责任；减少内部术语，解释公众关心的事项和行动路径。
### 完整稿要素
标题、受众称谓、背景与现状、核心事实、公众可理解的措施、行动或反馈渠道、结尾、署名日期。
### 禁止项
不得使用内部黑话、模糊责任或未经证实的承诺；不得虚构政策、民意、事件、数据和署名主体；不得写成会议讲话。

## 感谢信
### 用途
用于对具体个人、单位或群体在特定事件、工作或困难中的帮助表达正式感谢和敬意；核心要素是具体事由、实际帮助、实际影响。
### 必要结构
标题 → 明确收信对象 → 说明具体事由 → 写明帮助过程和真实影响 → 表达感谢敬意 → 署名、日期（按要求）。
### 语气
真诚、庄重、具体；情感应由事实承载，避免夸张和套话。
### 完整稿要素
标题、收信人或单位、时间场景、具体帮助、帮助解决的实际问题或影响、感谢与敬意、署名、日期。
### 禁止项
不得发明帮助、影响、人物关系、荣誉或结果，不得只写泛泛感谢，不得将感谢信写成宣传稿或工作总结。

## 通用真实性与交付检查
- 不得虚构事实、政策名称、数据、人物、单位、事件或成绩；材料没有的内容使用 `〔待补充〕`，不以常识补齐。
- 现场稿检查称谓、开场、听感过渡、主体和结束；非现场稿检查标题、称谓、正文、结尾、署名和日期是否按输入保留。
- 文种必须服从目的、场景、身份、受众和格式；若多个标签同时出现，以主要任务功能为准，不拼接成混合模板。
- 只输出目标文本，不输出“好的”“以下是”、说明、建议、检查结果或后记。
